PERSONAL USE · SELF HOSTED

Your files.
A clearer view.

Media Library brings the owner's Google Drive and MEGA accounts into a private file and media browser.

Browse original folders, search across connected storage, preview videos, and collect download links from one interface.

How your data is used ↗

One library, original storage.

01

Browse and preview

Use folder, combined storage, or media views. Search filenames and see thumbnails and muted video previews.

02

Manage your files

Use supported provider actions to create folders, rename or move files, and check account storage usage. Deletion follows the provider driver's behavior and can be permanent.

03

Download when needed

Collect private download links for a folder or connected storage. Optional JDownloader exports preserve the source folder structure.

GOOGLE ACCOUNT ACCESS

Permission with a purpose.

The owner connects each Google account through Google's sign-in and consent screen. Drive access lets the private library list and search existing files, display thumbnails, stream media, read storage usage, and perform file-management actions the owner requests.

The app requests full Drive file access because it browses existing files across the connected account. It stores a refresh token on the owner's host so normal access can refresh without repeated sign-in. Access can be revoked through Google Account connections.

This website provides app information and privacy disclosures. The library itself runs on the owner's computer and is reached through the owner's private connection. There is no public account signup here.
