Privacy policy

Effective November 12, 2026

Media Library is a personal-use, self-hosted application maintained by RayaanA. It helps its owner browse and manage files in accounts they choose to connect. This policy covers that application and this public information website.

Information the app accesses

When a Google account is connected, the app receives OAuth authorization tokens and reads the account email address and Drive permission identifier to identify the connection. Google passwords are entered on Google's own sign-in page and are not collected by the connector.

With the approved Drive permission, the app can access existing files and folders, including their names, identifiers, paths, sizes, modification dates, thumbnails, media metadata, file content requested for streaming or downloading, and account storage usage. Full Drive access also enables supported file-management actions such as creating folders, uploading, renaming, moving, or deleting files when requested through the private interface.

For a connected MEGA account, its provider credentials and any configured authentication settings are stored by the self-hosted backend. Similar file, folder, content, and capacity data are accessed to provide the library features.

How information is used

Account identifiers associate each connection with its storage location. Tokens authenticate requests and refresh access. File metadata supports listings, search, storage usage, and navigation. Requested file content supports playback, previews, downloads, and provider operations. The background preview worker reads limited portions of media to generate cached thumbnails; it can prepare MEGA root thumbnails while the library is running.

Google user data is used to provide these user-facing features. It is not sold, used for advertising, used to train generalized AI or machine-learning models, or used for an unrelated purpose.

Storage and retention

Account connection settings, refresh tokens, provider credentials, account identifiers, the search index, and generated preview data are stored on the owner's host. Backups may contain the same information. The library browser stores its login token and display preferences locally; the local account connector uses a temporary session cookie and server-side session memory.

Source files remain with the connected providers unless the owner requests a download, upload, move, copy, or deletion. Preview files and metadata can be retained locally. Removing a connection or revoking Google access does not automatically erase old backups or all cached data. The owner controls retention and must remove those copies separately when desired.

Sharing and transfers

The backend communicates with Google and MEGA to fulfill the requested features. Streams, metadata, and previews are sent to the owner's authorized browser or downloader. Private remote access can use Tailscale. Signed download links may be exported to software such as JDownloader at the owner's request; anyone given such a link and network access may be able to download its file.

Using the library does not automatically make provider files public. Explicit provider sharing or distributing a download link is a separate owner action. Account credentials and file lists are not published to this information website. The maintainer does not operate a central collection service for self-hosted library data.

Google user data is shared only as necessary to deliver the requested features, with the user's consent, or as required by applicable law. Human access is limited to what the owner authorizes or what is necessary for security, legal compliance, or operation of the owner-managed installation.

Security and your controls

The configured installation uses authenticated library access, a local account connector, private network access, and filesystem controls for runtime credentials. The owner is responsible for protecting their devices, backups, account credentials, and exported links.

You can revoke the app's Google permission at Google Account connections, remove a storage connection through the private library's administration interface, and delete its local data and backups. Revocation stops future authorized Google access but does not undo prior file operations. Some provider deletion actions are permanent.

Google API Services Limited Use

Media Library's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This public website

This static website has no account forms, application login, analytics scripts, or advertising trackers. It is hosted by GitHub Pages. GitHub may process connection information such as IP addresses and request logs under the GitHub General Privacy Statement. Following an external link subjects that visit to the destination's privacy practices.

Contact and changes

For support or privacy questions, contact the operator through the support email displayed on the Google consent screen, or use the app information repository's issue tracker. The tracker is public: do not post passwords, authorization tokens, private file details, or other sensitive information.

Changes to the app's data practices will be reflected on this page with an updated effective date.
